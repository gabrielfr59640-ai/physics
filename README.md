# Physics Vectors (Geode)

Placer le dossier a la racine d'un depot GitHub, definir `GEODE_SDK`, puis pousser :
le workflow `.github/workflows/build.yml` compile iOS / Android / Windows / macOS.
Local : `geode build` (CLI Geode).

Avant la premiere compilation : remplacer `yourname` dans `mod.json`, ajuster `"geode"` a la version du SDK utilisee.
